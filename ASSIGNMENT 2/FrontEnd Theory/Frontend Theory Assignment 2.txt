1. What is CSS Box Model?

The CSS Box Model describes how every HTML element is represented as a rectangular box. It consists of four parts:

Content – The actual text, image, or other content.
Padding – Space between the content and border.
Border – A line surrounding the padding and content.
Margin – Space outside the border that separates the element from other elements.

2. What is Media Query? Explain with a sample code?

A media query in CSS is used to make a website responsive. It allows us to apply different CSS styles depending on the screen size, device, or orientation.
example-
body {
    background-color: white;
}

@media screen and (max-width: 600px) {
    body {
        background-color: light blue;
    }
}

3. What are the features of Bootstrap?

Bootstrap is a popular open-source CSS framework used for developing responsive and mobile-first websites.

Main features:
Responsive design – Websites automatically adjust to different screen sizes.
Grid system – Provides a 12-column grid for creating layouts.
Predefined CSS classes – Provides ready-made classes for styling.
Components – Provides buttons, cards, navbar, alerts, modals, etc.
Mobile-first approach – Designed first for smaller screens.
JavaScript components – Provides interactive components such as dropdowns and carousels.
Easy to use – Can be used with simple HTML and CSS classes.
Cross-browser compatibility – Works across commonly used browsers.

5. What are CSS Selectors?

CSS selectors are used to select HTML elements on which we want to apply CSS styles.

Common types of selectors:
1. Element Selector

Selects all elements of a particular type.

p {
    color: blue;
}

This applies to all <p> elements.

2. ID Selector

Selects an element using its ID.

#heading {
    color: red;
}
3. Class Selector

Selects elements using a class.

.box {
    background-color: yellow;
}
4. Universal Selector

Selects all elements.

* {
    margin: 0;
}
5. Group Selector

Applies the same style to multiple elements.

h1, p {
    color: green;
}

6. What are CSS backgrounds? List the properties.

CSS background properties are used to control the background appearance of an HTML element.

Important background properties:
background-color – Sets the background color.
background-image – Adds an image as background.
background-repeat – Controls whether the image repeats.
background-position – Sets the position of the background image.
background-size – Controls the size of the background image.
background-attachment – Controls whether the background scrolls with the page.
background – Shorthand property for setting multiple background properties.

7. How can we overlap elements in CSS?

Elements can be overlapped using positioning properties and the z-index property.

Usually, we use:

position: relative
position: absolute
z-index
Example:
.box1 {
    position: relative;
    width: 200px;
    height: 200px;
    background-color: red;
}

.box2 {
    position: absolute;
    top: 50px;
    left: 50px;
    width: 100px;
    height: 100px;
    background-color: blue;
}

Here, .box2 is positioned over .box1.

We can use z-index to control which element appears on top.

.box1 {
    z-index: 1;
}

.box2 {
    z-index: 2;
}

8. What are the different positioning properties in CSS?

The CSS position property specifies how an HTML element is positioned on a webpage.

There are five main values:

1. Static

Default position of an element.

position: static;

The element follows the normal document flow.

2. Relative

The element remains in its normal position but can be moved relative to its original position.

position: relative;
top: 20px;
3. Absolute

The element is positioned relative to its nearest positioned ancestor.

position: absolute;
top: 10px;
right: 20px;
4. Fixed

The element remains fixed at a particular position even when the page is scrolled.

position: fixed;
bottom: 10px;
right: 10px;
5. Sticky

The element behaves normally until a specified scrolling position is reached, then it sticks to that position.

position: sticky;
top: 0;

9. What is ECMAScript?

ECMAScript is a standard/specification that defines how scripting languages should work. JavaScript is the most popular implementation of ECMAScript.

ECMAScript defines features such as:

Variables
Data types
Functions
Objects
Classes
Loops
Arrays
Promises and other language features

For example:

let name = "Utkarsh";
console.log(name);

JavaScript follows the ECMAScript standard, which is maintained by ECMA International.

10. Difference between var, let and const in JavaScript. Explain Temporal Dead Zone.

In JavaScript, var, let, and const are used to declare variables. They differ mainly in their scope, redeclaration, reassignment, and hoisting behavior.

Difference between var, let, and const

Feature			var			let			const
Scope			Function scope		Block scope		Block scope
Redeclaration		Allowed			Not allowed		Not allowed
Reassignment		Allowed			Allowed			Not allowed
Hoisting		Yes			Yes, but TDZ applies	Yes, but TDZ applies
Initialization required	No			No			Yes.
